# DP를 이용한 풀이

이 문제는 BFS뿐만 아니라 DP로도 해결할 수 있다.

```cpp
dp[i] = 합 i를 만들기 위해 필요한 최소 동전 개수
```

합 `0`은 아무 동전도 사용하지 않으므로

```cpp
dp[0] = 0;
```

으로 시작한다.

각 합 `i`에서 사용할 수 있는 동전 `v[j]`를 하나씩 확인하며 다음과 같이 갱신한다.

```cpp
dp[i] = min(dp[i], dp[i - v[j]] + 1);
```

`dp[i - v[j]]`는 현재 동전 `v[j]`를 사용하기 전 합을 만드는 최소 동전 개수이고, 여기에 현재 동전 하나를 추가하므로 `+1`을 한다.

예를 들어 합 `7`을 만들 때 동전이 `2, 3, 5`라면 다음 경우를 비교한다.

```cpp
dp[7] = min(dp[7], dp[5] + 1); // 2 사용
dp[7] = min(dp[7], dp[4] + 1); // 3 사용
dp[7] = min(dp[7], dp[2] + 1); // 5 사용
```

이 중 가장 작은 값이 `dp[7]`에 남는다.

```cpp
for (int i = 1; i <= m; i++)
{
    for (int j = 0; j < n; j++)
    {
        if (i - v[j] >= 0)
        {
            dp[i] = min(dp[i], dp[i - v[j]] + 1);
        }
    }
}
```

이 문제에서는 같은 종류의 동전을 여러 번 사용할 수 있으므로 이미 계산한 작은 합의 `dp` 값을 다시 사용하는 것이 가능하다.

## 핵심

```cpp
dp[i] = min(dp[i], dp[i - v[j]] + 1);
```

현재 합 `i`를 만들 때 **마지막에 동전 `v[j]` 하나를 사용했다고 생각하고**, 그 직전 합의 최소 동전 개수에 `1`을 더해 비교하는 방식이다.
