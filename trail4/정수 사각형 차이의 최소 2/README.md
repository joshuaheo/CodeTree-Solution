# 개선점 및 배운 점

## 1. `min`, `max`를 동시에 저장하는 DP의 문제점

처음에는 각 칸에 현재 경로의 최솟값과 최댓값을 함께 저장했다.

```cpp
dp[row][col] = {minValue, maxValue};
```

이후 두 경로 중 현재 `max - min` 값이 더 작은 경로를 선택하려 했지만, **현재 차이가 작다고 해서 최종 경로에서도 더 좋은 경로라는 보장이 없다.**

예를 들어 현재 상태가 다음과 같을 수 있다.

```text
A : min = 0, max = 9  → 차이 9
B : min = 7, max = 18 → 차이 11
```

현재는 A가 더 좋아 보이지만 이후 값 `15`를 지나면

```text
A → min = 0, max = 15  → 차이 15
B → min = 7, max = 18  → 차이 11
```

처럼 결과가 역전될 수 있다.

따라서 한 칸에서 현재 차이가 작은 `{min, max}` 하나만 남기는 방식으로는 해결할 수 없다.

동률인 경우에만 재귀적으로 두 경우를 모두 탐색하는 방식 역시 충분하지 않으며, 분기가 반복되면 경우의 수가 크게 증가하여 시간복잡도 측면에서도 불리하다.

---

## 2. 최솟값 `low`를 고정하여 상태 단순화

최솟값과 최댓값을 동시에 최적화하기 어렵기 때문에, 경로에서 사용할 수 있는 최솟값 `low`를 하나씩 고정한다.

```cpp
for (int low = 1; low <= temp; low++)
```

`low`보다 작은 값은 현재 경로에서 사용할 수 없도록 처리한다.

```cpp
if (v[row][col] < low)
{
    continue;
}
```

이렇게 최솟값 조건을 바깥 반복문에서 고정하면 DP 내부에서는 최솟값까지 함께 관리할 필요가 없어진다.

즉,

```text
최솟값 + 최댓값을 동시에 관리
```

하던 문제를

```text
최솟값 low 고정
→ 해당 조건에서 최댓값만 최소화
```

하는 문제로 바꿀 수 있다.

---

## 3. `low`의 탐색 범위와 문제 조건

모든 경로는 시작점과 도착점을 반드시 지나야 한다.

따라서 경로의 최솟값은 다음 값보다 클 수 없다.

```cpp
int temp = min(v[0][0], v[n - 1][n - 1]);
```

예를 들어 시작점이 `20`, 도착점이 `30`이라면 경로에는 반드시 `20`이 포함되므로 경로의 최솟값이 `21` 이상이 될 수 없다.

따라서

```cpp
for (int low = 1; low <= temp; low++)
```

까지만 검사하면 된다.

또한 이 방식은 **격자에 들어가는 값의 범위가 작다는 문제 조건 때문에 효율적으로 사용할 수 있다.**

이 문제에서는 값의 범위가 제한되어 있으므로 가능한 `low`를 하나씩 전부 검사해도 반복 횟수가 많지 않다.

만약 값의 범위가 매우 커서 `1 ~ 1,000,000,000`과 같았다면 모든 `low`를 하나씩 검사하는 방식은 사용할 수 없고, 실제 격자에 존재하는 값만 후보로 사용하거나 다른 최적화 방법이 필요하다.

즉, `low`를 완전탐색하는 방식은 **값의 범위가 작다는 조건을 활용한 풀이**이다.

---

## 4. `low`가 실제 경로의 최솟값이 아니어도 되는 이유

`low`는 항상 실제 경로의 최솟값과 일치하는 것은 아니다.

예를 들어 실제 경로가

```text
5 → 8 → 10
```

이라면 실제 차이는

```text
10 - 5 = 5
```

이다.

하지만 `low = 3`일 때도 이 경로는 모두 `3` 이상이므로 사용할 수 있다.

이 경우 계산되는 값은

```text
10 - 3 = 7
```

로 실제 차이보다 크게 계산된다.

```text
low = 3 → 10 - 3 = 7
low = 4 → 10 - 4 = 6
low = 5 → 10 - 5 = 5
```

`low`가 실제 최솟값보다 작으면 결과를 실제보다 크게 계산할 뿐, 더 작은 잘못된 정답을 만들지는 않는다.

모든 `low`를 검사하면 결국 실제 경로의 최솟값과 `low`가 일치하는 경우도 검사하게 되므로 정확한 차이를 얻을 수 있다.
