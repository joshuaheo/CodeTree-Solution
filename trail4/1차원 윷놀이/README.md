# 개선점 및 배운 점

* DFS에서 `index`는 **현재 처리할 이동 번호**를 의미하도록 두는 편이 좋다. `-1`에서 시작하거나 이전 선택 정보를 따로 넘기면 인덱스가 한 칸씩 어긋나 실수하기 쉽다.

* 반면 `counting`처럼 **값으로 전달되는 변수**는 현재 값을 직접 변경하지 않고 다음 재귀 호출에 계산된 값을 넘기면 복구할 필요가 없다.

  ```cpp
  finding(..., counting + arrival);
  ```

* 이미 도착한 말을 다시 선택하지 않는 것처럼 의미 없는 경우를 제거하는 **가지치기**는 최악의 시간복잡도가 같더라도 실제 실행시간을 크게 줄일 수 있다.

* 재귀 함수에서 `vector`를 값으로 전달하면 호출마다 전체 복사가 발생한다. 상태를 직접 수정하고 복구할 수 있다면 참조 전달을 사용해 복사 비용을 줄일 수 있다.

* `arrival`처럼 특정 반복에서만 사용하는 임시 변수는 `for`문 내부에서 선언하면 별도로 초기 상태로 복구할 필요가 없다. 변수의 사용 범위를 필요한 곳까지 좁게 두는 것이 좋다.

* 완전탐색의 시간복잡도가 같더라도 실제 방문하는 재귀 노드 수, 벡터 복사, 반복문 등의 차이로 실행시간이 크게 달라질 수 있다. 특히 DFS/백트래킹에서는 **불필요한 탐색을 줄이는 것**이 중요하다.
