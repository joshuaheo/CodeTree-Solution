# DP 풀이 정리

## 1. DP 배열의 의미

```cpp
vector<int> dp(m + 1, n + 1);
dp[0] = 0;
```

`dp[j]`는 다음 의미를 가진다.

```text
dp[j] = 합 j를 만들기 위해 필요한 최소 원소 개수
```

합 `0`은 아무 원소도 선택하지 않으면 만들 수 있으므로

```cpp
dp[0] = 0;
```

으로 초기화한다.

나머지는 아직 만들 수 없는 상태이므로 최대 선택 개수보다 큰 `n + 1`로 초기화한다.

---

## 2. 현재 원소를 이용해 새로운 합 만들기

```cpp
for (int i = 0; i < n; i++)
{
    for (int j = m; j >= a[i]; j--)
    {
        if (dp[j - a[i]] != n + 1)
        {
            dp[j] = min(dp[j], dp[j - a[i]] + 1);
        }
    }
}
```

현재 원소가 `a[i]`일 때,

```cpp
dp[j - a[i]]
```

를 만들 수 있었다면 현재 원소 하나를 추가하여 합 `j`를 만들 수 있다.

따라서

```cpp
dp[j] = min(dp[j], dp[j - a[i]] + 1);
```

로 갱신한다.

예를 들어 합 `10`을

```text
2 + 3 + 5 = 3개
4 + 6     = 2개
```

두 가지 방법으로 만들 수 있다면

```text
dp[10] = 2
```

만 저장한다.

같은 합이라면 이후 사용할 수 있는 원소는 동일하므로 원소를 적게 사용한 경우만 남기면 된다.

---

## 3. DP 배열을 역순으로 탐색하는 이유

```cpp
for (int j = m; j >= a[i]; j--)
```

갱신식은

```cpp
dp[j] = min(dp[j], dp[j - a[i]] + 1);
```

이고 항상

```text
j - a[i] < j
```

이다.

따라서 큰 인덱스부터 작은 인덱스 방향으로 탐색하면 `dp[j - a[i]]`는 현재 `a[i]`에 의해 아직 갱신되지 않은 값이다.

즉 현재 원소를 사용해서 만든 값을 같은 반복에서 다시 사용할 수 없다.

### 정방향 탐색

숫자 `3`이 하나만 있어도

```text
dp[3] = dp[0] + 1
dp[6] = dp[3] + 1
```

처럼 방금 만든 `dp[3]`을 다시 사용하여 `3 + 3`을 만든 것처럼 처리될 수 있다.

### 역방향 탐색

```text
dp[6] 확인
↓
dp[3] 갱신
```

순서가 되므로 같은 인덱스의 원소는 한 번만 사용된다.

값이 같은 서로 다른 원소가 여러 개 존재한다면 각각 다른 반복에서 처리되므로 정상적으로 여러 번 사용할 수 있다.

# 핵심 정리

```text
dp[j] = 합 j를 만드는 최소 원소 개수
```

현재 원소 `a[i]`를 사용할 수 있다면

```cpp
dp[j] = min(dp[j], dp[j - a[i]] + 1);
```

로 최소 개수를 갱신한다.

각 원소는 한 번만 사용할 수 있으므로 `dp` 배열을 역순으로 탐색한다.

```text
정방향 → 현재 원소를 같은 반복에서 다시 사용할 수 있음
역방향 → 현재 원소를 한 번만 사용
```
